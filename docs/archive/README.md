# Archived documentation

Historical documents describing retired architectures — kept for the record,
not maintained. The hackathon-era docs here (TECHNICAL, PROJECT, AI_BUILD_LOG,
ONCHAIN, EXTRAS) describe the original 2-of-2 / ERC-4337 / inline-screening /
JSON-file design, all of which was replaced by the SafeTx flow, the Supabase
backend, and the runtime job protocol (D0–D5). For the current architecture,
see the live docs in `docs/` and the package READMEs.
